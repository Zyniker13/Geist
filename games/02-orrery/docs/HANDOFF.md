## How to build and run

```bash
cd games/02-orrery
make gen      # xcodegen generate --spec project.yml
make build    # iOS (zGeist_bot-iPad-Pro-13 destination) + macOS, Debug
make test     # swift test × 7 packages + xcodebuild test (iPad sim)
make lint     # SwiftLint --strict + swift-format + content-lint + check-imports
```

The app launches to a placeholder menu ("Orrery"); gameplay arrives in P1/P2.

## Architecture

See `docs/ARCHITECTURE.md` (arrives with the P1 engine). Package direction:
`ORCore ← ORContent ← ORAI ← ORMeta ← ORRender/ORAudio/ORPlatform ← App`.
Rules math is integer-only (`Int`, `Angle48`, `Fixed` Q32.32); randomness only
via `SeededRNG`; the reducer contract and replay format live in
`ORCore/Replay/` (trivial state until P1 swaps in `GameState`).
