# Murmuration — Third-Party Components

None. Murmuration uses only Apple system frameworks (SwiftUI, Metal/MetalKit,
AVFoundation, GameKit, CloudKit) and first-party code in this repository. No
third-party dependencies, assets, or fonts are in use, so no attribution entries are
required yet. Any future dependency must be on the `_CONVENTIONS.md` §4.4 allow-list
and will be listed here with its license and attribution text.
